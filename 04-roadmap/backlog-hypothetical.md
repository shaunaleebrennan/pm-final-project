# Backlog: security questionnaire answer check (hypothetical)

> **Hypothetical backlog.** The course backlogs only cover StreamLine and RouteLogic, so I wrote these 10 feature proposals for my own initiative from my Module 2 sample data and Module 3 metrics snapshot. They are assumptions, not requests from real stakeholders. The AI baseline scores came from pasting the Lab 1 "Senior PM" prompt (with my anchors) into an LLM.

**Team (assumed):** 2 engineers + 1 designer · **Window:** 4-week pilot with 3 sales teams, then weeks 5 to 8 (matches my Module 3 decision window of 8 weeks and 20 questionnaires).

| # | Feature | What it does | Origin |
|---|---|---|---|
| S1 | Change-Impact Flags | When a certification, region or policy changes, flag every library answer that mentions it | M2 UXR (H-06, H-10) |
| S2 | Pre-Submission Answer Check | Check a drafted questionnaire against current certifications, regions and policies before it's sent; flag outdated answers | M3 Data (42% sent "to confirm") |
| S3 | Flagged-Only Security Queue | Send security only the flagged answers, with the changed control attached, ordered by due date | M2 Journey Map (T-02, T-05) |
| S4 | Source & Date on AI Drafts | Show the source document and its date beside each AI-drafted answer | M2 Interview (H-02, T-06) |
| S5 | Answer Owner Assignment | Give every high-risk library answer a named owner | M3 Data (6% of entries owned) |
| S6 | Save Security Decisions to Library | Write each security decision back to the answer library so the next deal reuses it | M2 Journey Map (T-05) |
| S7 | AI Auto-Complete Whole Questionnaire | AI drafts all 250 answers in one click | Sales Request |
| S8 | Buyer Portal Auto-Submit | Push answers straight into buyer questionnaire portals | Sales Request |
| S9 | Questionnaire Format Preserver | Keep spreadsheet, portal and PDF formatting intact on copy-paste | Engineering (T-07) |
| S10 | Trust Centre Sync | Update the public trust centre when a sub-processor or certification changes | Legal / Security (T-08) |
