# Security Questionnaire Answer Check: Product Management Final Project

> My final project for Product School's **Product Management** certification. One B2B product concept, taken from a raw problem to a launch-ready plan across six modules, with one module committed per class.

## The project in one sentence

A pre-submission check for enterprise security questionnaire answers: for sales engineers and the security teams who review their work, betting that checking each answer against current certifications, data residency and policies before it's sent will cut security review load and stop outdated answers from reaching contracts.

## The problem

Security questionnaires sit in almost every enterprise SaaS deal. Sales engineers now copy answers from past questionnaires and let AI fill the gaps, so answers that were true last year (a certification scope, a data residency option, a policy) end up in this year's contracts. The security team becomes a review bottleneck, and late-stage deals stall. Full detail: [problem hook & value proposition](01-product-thinking/problem-hook.md).
